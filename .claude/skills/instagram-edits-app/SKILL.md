## {User}'s Edits-First Workflow

### Phase 1: Ideation (Edits Weekly Ideas)
1. Open Edits -> Weekly Ideas Tab (10 personalisiert pro Woche)
2. Format gegen bewaehrte Reel-Formate pruefen (`reel-template`)
3. Speichern direkt im Edits Storyboard
4. Auto-sync nach Notion Content-Pipeline DB (manuell via screenshot/PDF export)

### Phase 2: Storyboard (vor Drehtag)
1. Edits -> New Storyboard
2. Pro Slot: 2-3 Multi-Takes planen (Hook / Mid / CTA)
3. Mit `reel-template` Skill cross-checken (6 Proven Formats)
4. Notion DB Update: Status "Storyboarded"

### Phase 3: Capture (am Drehtag)
1. Edits Camera oeffnen (NICHT IG Main App!)
2. Resolution: 4K HDR / 30fps fuer Process-Reels, 60fps fuer Skulptur-Movement
3. Teleprompter aktivieren bei Talking-Head (Statement, Pitch, Grant-Bewerbung)
4. Green Screen fuer Studio-Sequenzen ohne Background-Mess

### Phase 4: Edit
1. Import Storyboard takes
2. Audio: {DEIN_PROJEKT} Track -> Beat Markers ON -> snap cuts to dots
3. Captions: Auto-Generate -> Switch DE/EN (2 Versionen exportieren!)
4. Effects: Max 1-2 (bounce hook + cinematic transition), nicht over-editen
5. Keyframe text reveals to beat drops
6. In-Video Link einfuegen: @yourproject oder @yourproject.music oder eigenes Reel

### Phase 5: Export & Publish
1. Export 4K HDR, kein Watermark (immer!)
2. Save als IG Draft direkt aus Edits
3. Cross-post: 1080p Version fuer TikTok/YouTube Shorts (4K HDR ist bei TikTok overkill)
4. Caption via `instagram-caption-generator` Skill
5. Post via Notion Content-Pipeline DB

### Phase 6: Analyze
1. Edits -> Insights Tab (24h, 7d, 30d nach Post)
2. AI Comment Summary lesen -> naechstes Reel-Thema ableiten
3. Compare Tool: Swipe durch letzte 5-10 Reels
4. Insights als PDF -> `werkbeitraege-2026/reach-nachweis-2026-04.pdf`

## Edits vs. Pipeline-Entscheidung

**Edits nutzen wenn:**
- Phone-First Capture (auf der Strasse, im Studio, Reise)
- < 10 Minuten Footage
- Solo-Talking-Head, Process-Reel, Quick-Turn
- Beat-Sync zu Audio
- In-Video Link zu Cross-Account brauchst
- Auto-Caption in 2 Sprachen brauchst

**AE/Resolume Pipeline nutzen wenn:**
- 4K Mural Time-Lapse (mehrere Stunden Footage)
- Komplexe Motion-Graphics (Studio-Standard)
- Mehrere Audio-Spuren mit precise mixing
- Custom Shader / Particle Effects
- > 10 Minuten Source Material
- Live Performance Capture (Resolume + OSC)

## NIEMALS (Anti-Patterns)

1. NIEMALS CapCut nutzen wenn Edits genauso gut ist (Datenschutz + Watermark)
2. NIEMALS 4K HDR nach TikTok hochladen (komprimiert eh, verschwendet Storage)
3. NIEMALS Auto-Caption ohne manuellen Spell-Check (Eigennamen wie "{DEIN_PROJEKT}", Marken- und Ortsnamen werden oft falsch transkribiert)
4. NIEMALS Storyboard ueberspringen bei wichtigen Reels (Grant-Bewerbung, Galerie-Pitch)
5. NIEMALS in-Video Link auf externe URL erwarten - nur auf IG Reels/Accounts
6. NIEMALS Edits Reel direkt von Edits posten ohne Caption via `instagram-caption-generator`
7. NIEMALS Insights nur in Edits lassen - Screenshot/PDF -> `docs/platforms/` archivieren
