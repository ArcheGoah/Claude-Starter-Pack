# Claude-Mem — Memory Management Plugin

Sub-commands available:
- `do` — Execute phased implementation plans with subagents
- `make-plan` — Create structured implementation plans
- `mem-search` — Search through memory and conversation history
- `smart-explore` — Intelligently explore codebase with context
- `timeline-report` — Generate timeline reports of activity

Each sub-command has its own SKILL.md with detailed instructions.
